# Data Preparation and Analysis (MTAI-PE1-20)

## Project Description
This project demonstrates end-to-end data preparation, cleaning, Exploratory Data Analysis (EDA), static & interactive visualization, and feature engineering using Python on the **Students Performance in Exams** dataset.
